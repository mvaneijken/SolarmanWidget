# SolarmanWidget

This Garmin Connect IQ Widget allows you to monitor your solar output from your Solarman PV System on your Garmin Connect IQ device

This widget requires the following to run correctly:
- a Garmin Connect IQ Smartwatch or device
- a smartphone/tablet with an active internet connection and paired with your smartwatch or device using Garmin Connect
- your Solarman Username and Password configured in the settings of the widget in Garmin Express or the Connect IQ app
