# SolarmanWidget

This Garmin Connect IQ Widget allows you to monitor your solar output from your Solarman monitoring subscription on your Garmin Connect IQ device. This widget replaces the Omnik widget.

Note: This widget is currently still in development, it might contain bugs.

This widget requires the following to run correctly:
- a Garmin device that supports Garmin Connect IQ v3.0 or higher;
- an internet connected Android or iOS device with the Garmin Connect App installed;
- the Garmin device must be paired with the Android or iOS device where the Garmin Connect App is installed;
- the Solarman monitoring credentials are configured in the settings of the widget, which can be done using Garmin Express (PC) or the Garmin Connect IQ app

This widget supports Glances for the devices that support this (like the Forerunner 945).
